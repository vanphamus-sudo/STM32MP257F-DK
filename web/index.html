HELP FOR EVERYDAY USERS

Start here: your router guide

This router connects your local devices to an Internet service, usually a mobile SIM. You can use the settings below without understanding every networking term. Start with the connection checks, then change only the feature you need.

  1. Keep a way back in. Connect your computer by USB and open 192.168.7.1:8081. On the normal Ethernet LAN, use 192.168.10.1:8081. Sign in with the account supplied by your router owner.
  2. Check before changing. In Network overview, look for LTE connected and an address. Connect a client and try a website. A setting being enabled does not by itself prove a connection is working.
  3. Make one change at a time. Read the help beside that feature, record your old values and choose Save or Apply. Typing in a box does not save it. The examples in this guide are illustrations and never fill in your settings automatically.
  4. Follow the result message. Ethernet/USB role settings may need a reboot and a renewed computer lease. Some advanced changes ask you to confirm access within three minutes; if that prompt appears, test before confirming or the previous settings will be restored.
  5. Check the result. Use the feature help section titled How to check. Download a settings backup before a major change; it contains passwords/keys, so store it privately.
If you lose access: try USB management first. A long USER1 press until orange LD9 stays on (about eight seconds), followed by release, restores the Ethernet/USB management configuration and reboots. This is network recovery, not a full erase of every setting. A short USER1 press reboots. Physical recovery still needs acceptance testing on this kit; keep the installer recovery instructions available.
Words used in this guide
LAN / WAN / uplink
LAN is your nearby devices. WAN or uplink is the connection toward the Internet. A port is sometimes a physical socket; in service settings it means a numbered network service.
IP address / subnet / prefix
An IP address identifies a network connection. A subnet is an address group. 192.168.10.0/24 describes the normal 192.168.10.x LAN; /32 means one IPv4 address. Do not assign the same address to two devices.
MAC address / reservation
A MAC is an interface hardware identifier, such as 02:11:22:33:44:55. A reservation links that identifier to a stable local IP address. Example MACs must be replaced with your actual device MAC.
DHCP / lease / DNS / gateway
DHCP lends a device its network settings for a lease period. Renewing a lease asks for current settings again. DNS looks up website names. A gateway forwards traffic to other networks.
VLAN / managed switch
A VLAN separates networks on shared Ethernet cables. A managed switch must be configured to match the VLAN numbers. VLAN settings are an installer task if you are unfamiliar with them.
VPN / TLS / certificates and keys
A VPN links networks through an encrypted tunnel. TLS encrypts services such as MQTT or file uploads. Certificates help verify identity. Private keys are secrets; public keys can be shared with the intended administrator. An update signing key and a TLS certificate are different things.
NAT / carrier NAT
NAT lets private devices share an address. Your mobile carrier may also use NAT, which can prevent outside connections even when you configure forwarding, DMZ, DDNS or passthrough.
MB / MiB / Mbit/s / kbit/s
MB and MiB measure data amounts and are slightly different units. Mbit/s and kbit/s measure speed: 1 Mbit/s is 1000 kbit/s. Use the unit shown next to each setting.

    USB tethering

    USB Ethernet and tethering remain available. USB management stays at 192.168.7.1, and DHCP always supplies a PC address.

    On advertises the router as the USB default gateway and DNS server. Off supplies an address without gateway or DNS advertisements, so your PC can keep its Ethernet internet connection. With both gateways available, Windows route metrics determine which is preferred. Reboot after saving, then reconnect USB or renew the PC lease. Internet access depends on the active uplink and SIM/APN.

    Hold USER1 until orange LD9 stays on (eight seconds), then release to restore USB management and Ethernet LAN with USB gateway advertisements off.

    DATA COLLECTION

    Modbus RTU and FTP

    Disabled

    Collect meter registers into a CSV file for each device. Files close at the daily upload time and transfer to FTP; failed transfers retry every minute. Times use the router's local clock. Use a dedicated RS485 or RS232 adapter.

    Expired files are removed after the retention period, including failed uploads. Collection pauses at the storage limit. Mount USB storage before enabling USB mode; missing USB storage stops collection.

    Serial settings

    Set these to match your meter before adding registers. The guide's example uses 9600 baud, no parity, 8 data bits and 1 stop bit. Save with Apply Modbus settings below.

    FTP server

    Devices and registers

    Device IDs must be unique. Addresses are zero-based decimal or 0x hex. Select function 03 or 04 from your meter's register map. Little-endian swaps the two words of a 32-bit value; bytes within each word stay in Modbus order.

    Apply settings to start collection.

    Saved data

    Collecting files are still receiving readings. Pending files await FTP; uploaded files remain available until expiry. The latest 1,000 files are listed.

      FIREWALL

      Port forwarding

      Forward incoming IPv4 connections to an Ethernet or Wi-Fi client. The client needs a stable IP address and must use this router for its return route. LTE carrier NAT or upstream firewalls can prevent inbound access.

      Open this section to load rules.

      DMZ host (WAN / LTE)

      Forward all unmatched incoming IPv4 traffic, including non-TCP/UDP protocols, to one client. Specific port forwards take priority. This exposes the client and can redirect services normally reached on the router's WAN address. It does not isolate the client from its local network.
